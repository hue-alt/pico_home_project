# Pico Home Environmental and Safety Monitoring System

A distributed multi-node environmental, meteorological, and household safety monitoring system built on Raspberry Pi Pico 2 W microcontrollers (RP2350 with CYW43439 wireless subsystem) utilizing the official Raspberry Pi Pico SDK.

## Overview

The system collects, processes, and displays real-time telemetry from multiple areas using a star network topology over Wi-Fi.

The architecture comprises three dedicated stations, each responsible for a specific monitoring environment:

- **RoomStation**: Serves as the central coordinator. It creates an autonomous Wi-Fi Access Point, runs a UDP server, maintains calendar time via an RTC module, measures local room metrics, and renders multi-page views on an OLED screen.
- **KitchenStation**: Monitors kitchen safety, detecting combustible gas leaks, carbon monoxide, carbon dioxide levels, dust concentration, and noise. It provides immediate local feedback via dual RGB LEDs and transmits data to the RoomStation.
- **OutsideStation**: Operates as a weather station, measuring external ambient temperature, internal enclosure temperature, humidity, barometric pressure, UV index, solar light intensity, rain, and wind vibrations. It reports periodic readings to the RoomStation.

## Sensors and Hardware Components

- **AHT20**: Measures ambient temperature and relative humidity in RoomStation, and provides enclosure climate readings in OutsideStation.
- **DS18B20**: External waterproof temperature probe measuring outdoor air temperature.
- **BMP280**: Measures barometric atmospheric pressure and temperature with full 64-bit calibration compensation.
- **BH1750**: Digital ambient light sensor measuring outdoor solar illuminance in lux.
- **GUVA-S12SD**: Ultraviolet light sensor used to calculate the outdoor UV Index.
- **FC-37**: Rain sensor plate measuring surface moisture to detect rain presence and intensity.
- **SW-420**: Vibration sensor that counts physical pulses generated by wind gusts via hardware interrupts.
- **MQ-135**: Air quality sensor used to estimate carbon dioxide (CO2) concentration in PPM.
- **MQ-6**: Combustible gas sensor used for LPG, propane, and butane leak detection.
- **MQ-7**: Carbon monoxide (CO) sensor detecting toxic exhaust and combustion hazards.
- **Sharp GP2Y1010AU0F**: Optical dust sensor that uses an infrared emitter and receiver to calculate airborne particulate density in ug/m3.
- **MAX4466**: Electret microphone module with operational amplifier used to sample peak-to-peak sound amplitude and determine noise levels in dB.
- **TEMT6000**: Phototransistor light sensor tuned to the human eye response, used to measure room illumination in lux.
- **DS3231**: High-accuracy real-time clock with battery backup maintaining seconds, minutes, hours, date, and weekday.
- **SSD1306**: 128x64 monochrome OLED display presenting live telemetry screens.
- **Dual RGB LEDs**: Provide multi-level visual alerts for air quality, dust concentration, and emergency leak warnings.

## Wireless Communication

Data exchange is implemented over UDP using the lwIP network stack running in background thread-safe mode:
- **Network Mode**: RoomStation acts as the Wi-Fi Access Point (`SSID: PROJECT`), while KitchenStation and OutsideStation connect as client stations (STA mode).
- **Binary Transport**: Data is transmitted as compact binary payloads without text parsing or serialization overhead.
- **Transmission Cycle**: KitchenStation transmits its measurements every 1 second, while OutsideStation reports every 60 seconds.
- **Link Recovery**: Remote nodes actively check Wi-Fi connection health and automatically initiate reconnection in the event of packet or signal loss.

## User Interface and Visual Indicators

### RoomStation OLED Display
Two hardware buttons allow cycling through three dedicated live views:
- **Outdoor View**: Displays internal enclosure temperature, external probe temperature, relative humidity, barometric pressure, UV Index, sunlight level, rain level, and wind vibration count.
- **Kitchen View**: Displays carbon dioxide level, dust concentration, noise level, and safety warning banners indicating whether gas or carbon monoxide leaks have been detected.
- **Room View**: Displays the current weekday, date, and 24-hour time from the RTC, along with indoor temperature, humidity, lighting level, and noise level.

### KitchenStation RGB Indicators
Two RGB LEDs provide continuous local visual status:
- **Air Quality LED**: Indicates CO2 levels (green for good, yellow for elevated, red for poor).
- **Dust Density LED**: Indicates particulate levels (green for low, yellow for moderate, red for high).
- **Hazard Overrides**: If toxic carbon monoxide is detected, both LEDs blink red. If a combustible gas leak is detected, both LEDs blink blue.

## Building the Project

### Prerequisites
- Raspberry Pi Pico SDK (version 2.3.0 or newer).
- GCC ARM Embedded or RISC-V toolchain.
- CMake (version >= 3.13) and Ninja or Make.

### Build Steps

1. Navigate to the repository root:
   ```bash
   cd pico_home_project
   ```

2. Create and enter the build folder:
   ```bash
   mkdir build
   cd build
   ```

3. Configure CMake for Pico 2 W:
   ```bash
   cmake -DPICO_BOARD=pico2_w ..
   ```

4. Compile the binaries:
   ```bash
   cmake --build .
   ```

Compilation generates target UF2 firmware files in each respective station subdirectory inside `build/`.
